Privacy Policy

Apex Command Center · Last updated 7 September 2026

Apex Command Center is a private business-management tool operated by Resonate LLC for Apex Consultoria and its consulting clients. It is not offered to the general public and there is no public sign-up.

Who this covers

Access is limited to Apex staff and to businesses that Apex consults for, each of whom is issued credentials directly. Every user is a named individual known to the operator.

What we collect

  • Account data — name, email address, and role, so we know who is signed in.
  • Business records the user enters — clients, leads, meetings, invoices, documents, and notes.
  • Financial data — where a user connects a bank account through Plaid, transaction records used for bookkeeping and reporting.

Google account data

Apex Command Center can connect to a user's Google account. It requests only the narrowest permissions it needs, and each is used for one purpose:

  • Google Calendar (calendar) — to create and read calendar events for meetings booked inside Apex, so a consultant's Apex calendar and Google Calendar stay in step.
  • Google Drive file metadata (drive.metadata.readonly) — to check the last-modified time and the name of the last editor of specific spreadsheets a business previously used, so we can alert the operator when someone edits a spreadsheet whose data has already been migrated into Apex. This permission cannot read the contents of any file, and we do not read file contents.
  • Google Sheets (spreadsheets.readonly, where granted) — to read rows from a spreadsheet a user has explicitly asked Apex to import or compare against.

Apex's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What we never do

  • We do not sell or rent any data.
  • We do not use Google user data for advertising.
  • We do not use Google user data to train machine-learning models.
  • We do not transfer Google user data to third parties except as required to operate the service or to comply with law.
  • We do not allow humans to read Google user data except with the user's explicit permission, for security purposes, to comply with law, or where the data is aggregated and anonymised.

Where data is stored

Application data is stored in Cloudflare D1 and Cloudflare R2. Google OAuth refresh tokens are held as encrypted Cloudflare Worker secrets and are never exposed to the browser or written into application records. Bank connections are handled by Plaid; Apex does not store bank login credentials.

Retention and deletion

Business records are kept for as long as the engagement continues. A user may disconnect their Google account at any time from the Apex settings page, which deletes the stored refresh token immediately. To request deletion of any other data, contact us at the address below and we will action it.
